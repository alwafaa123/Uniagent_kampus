## 🌟 Tentang Proyek

**UniAgent Campus AI** adalah sistem pendukung layanan dan informasi kampus cerdas yang dirancang untuk membantu mahasiswa, dosen, serta civitas akademika dalam mengakses informasi seputar perkuliahan secara instan. Menggunakan pendekatan *Retrieval-Augmented Generation* (RAG) dan arsitektur modern, aplikasi ini mampu memberikan jawaban yang akurat, kontekstual, dan relevan berdasarkan data basis pengetahuan kampus.

---

## 🛠️ Tech Stack & Arsitektur

Proyek ini dibangun menggunakan teknologi modern untuk memastikan performa yang cepat, skalabel, dan andal:

* **Frontend:** [Next.js](https://nextjs.org/) (React Framework) dengan antarmuka yang responsif dan elegan.
* **Backend / API:** Layanan API terintegrasi (FastAPI / Node.js Express).
* **Database & Vector Search:** PostgreSQL dengan ekstensi `pgvector` untuk penyimpanan dan pencarian dokumen berbasis semantik.
* **AI & RAG Pipeline:** Integrasi model bahasa besar (LLM) untuk pemrosesan bahasa alami dan manajemen eskalasi layanan secara cerdas.
